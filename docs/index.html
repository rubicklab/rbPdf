RbPdf

Camada de alto nível em PHP para gerar PDFs com FPDF (pacote fawno/fpdf), com enums e value objects, componentes de tabela/lista e um escritor de template com header/footer padrão Rubick.

PHP 8.2+ Laravel 10+ UTF-8 na API Fluent interface PHPUnit
Ver esta página localmente: na raiz do repositório, execute php -S localhost:8765 -t docs e abra http://localhost:8765/index.html.

Integração Laravel

Após composer require rubick/rbpdf (VCS privado ou Packagist), o Composer regista o RbPdfServiceProvider. Corra o instalador para criar config/rbpdf.php no teu projeto:

php artisan rbpdf:install
php artisan rbpdf:install --no-assets   # só config
php artisan rbpdf:install --force       # sobrescrever ficheiros publicados

O provider expõe RbPdfConfiguration no container:

use Rubick\RbPdf\Config\RbPdfConfiguration;

$config = app(RbPdfConfiguration::class);

Publicação manual equivalente:

php artisan vendor:publish --tag=rbpdf-config
php artisan vendor:publish --tag=rbpdf-assets

Configuração e logos padrão

O ficheiro config/rbpdf.php do pacote define caminhos absolutos para public/img/logo-rubick-white.png e logo-rubick-footer.png dentro do próprio pacote (em vendor/ após o Composer). Podes sobrepor com variáveis de ambiente (RBPDF_HEADER_LOGO_PATH, RBPDF_FOOTER_LOGO_PATH, RBPDF_PUBLIC_PATH, PDF_FONTS_DIR, etc.) — ver docblock nesse ficheiro.

No Laravel, o stub publicado faz array_replace_recursive com o config do pacote e define paths.public para public_path(), para resolver assets relativos à pasta public da aplicação.

Primeiro PDF (sem framework)

composer install

<?php
require 'vendor/autoload.php';

use Rubick\RbPdf\Enum\RbPdfFontStyle;
use Rubick\RbPdf\RbPdf;

$pdf = new RbPdf;

$pdf
    ->addPage()
    ->font('Helvetica', RbPdfFontStyle::Regular, 12)
    ->cell(0, 10, 'Olá, RbPdf', 0, 1);

file_put_contents('saida.pdf', $pdf->toString());

Arquitetura

  • RbPdf — API fluente exposta à aplicação; delega ao motor interno FPDF.
  • RbPdfFpdfEngine / Bridge — tradução de tipos e operações para Fawno\FPDF, com traits de gradiente e alpha onde aplicável.
  • Componentes — RbPdfTableBuilder, RbPdfListBuilder, colunas e escritor de tabela.
  • RbPdfTemplateWriter — layout corporativo (barra de cor, logos, rodapé, Inter opcional via MakeFont).

Instanciação e isolamento

Cada new RbPdf() devolve uma instância nova com motor dedicado — adequado a filas, workers e pedidos HTTP em paralelo. Não há singleton com estado partilhado entre gerações.

Templates e RbPdfConfiguration

Para relatórios com o layout padrão, constrói RbPdfConfiguration::fromArray() a partir do array de config (Laravel: config('rbpdf') ou app(RbPdfConfiguration::class)) e passa ao RbPdfTemplateWriter. A estrutura de chaves está documentada em config/rbpdf.php.

Concorrência e cache TTF

Define RBPDF_CACHE_DIR (ou equivalentes usados pelos serviços de fonte) com cuidado em ambientes multi-processo: preferir diretório por worker ou token de teste (TEST_TOKEN / ParaTest) para evitar corrida em disco.
